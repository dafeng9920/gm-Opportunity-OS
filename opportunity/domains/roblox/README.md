# Roblox Opportunity Plugin v0.1

This domain plugin is an assessment layer only:

```
Candidate Packet + Roblox facts -> Generic Gate Engine + Roblox rules -> Roblox Opportunity Assessment -> Judge
```

It does not collect Roblox, YouTube, search, or SERP data; build a website; generate content; call Hermes; alter Core state; or make a commercial decision. The plugin returns `RobloxOpportunityAssessment` with gate facts, unknowns, and risk flags for the existing Judge contract.

Roblox rules are versioned `roblox-0.1`: search demand, SERP competition, content matrix, maintainable data sources, and defined monetization paths.
